# English documentation

These are English copies of the project's main documents. The French originals,
one folder up in `docs/`, remain the reference: when a copy and its original
disagree, the original is right, and a copy may lag behind a recent change.
The code comments are in French; the launcher speaks English, French and Japanese, and so do the messages of `tools/preparer.py`.

| Document | What it covers |
|---|---|
| [README](../../README.md) | the project, how to play (launcher, settings, gamepad), how to build |
| [assets.md](assets.md) | reading and modifying the game's files: texts, scripts, 2D graphics, `.srl` archives |
| [scripts.md](scripts.md) | the game's script language: stages, enemies, paths |
| [plan_portage.md](plan_portage.md) | the porting approach: static recompilation, then proven native rewrites |
| [plan_framerate.md](plan_framerate.md) | the decoupled high-framerate display |
| [reference.md](reference.md) | the reference: build chain, runtime, what is known about the game, environment variables, proof benches, modification points |
| [format_bmg.md](format_bmg.md) | dialogue files (`.bmg`) |
| [format_ntfq.md](format_ntfq.md) | flat textures of the HUD, menus and effects (`.ntfq`) |
| [format_mdl.md](format_mdl.md) | 3D models and their chunk container (`.mdl`, `.tset`, `.anim`) |
| [format_hgt.md](format_hgt.md) | ground collision (`.hgt`) |
| [format_audio.md](format_audio.md) | the sound archive (`.sdat`) |

Not translated: tables generated by the tools, readable as they are (names,
addresses, sizes), and one historical note.
